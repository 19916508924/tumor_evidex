# Evidex 人工知识更新前端验收计划

## 输入与入口

- 运营总览提供“发起知识更新”主入口；导航提供“待审核证据”。
- 创建页接受全库或指定疾病、基因、变异范围，文献上限为 50、100 或全部，可选时间窗。
- 候选页接受 PMID 与一条已存在的治疗关联。
- 运行详情接受暂停、继续和取消；审核页接受草稿修改、退回、拒绝与审核发布。

## 可观察输出与正常路径

- 指定范围至少选择一个实体后才能预览；预览展示规范范围、时间窗、子查询、预计数量、警告和失效时间。
- 普通上限可从预览直接确认；“全部文献”必须经过第二个明确确认动作。
- 创建成功后进入对应运行详情；重复确认沿用同一幂等键。
- 单篇 PMID 成功后显示其已进入整理流程，并提供候选或审核入口。
- 审核队列可搜索、按状态筛选并进入三栏审核工作台。
- 运行详情显示范围、处理进度、分类计数、子查询和候选；运行中可暂停或取消，暂停后可继续。

## 边界与失败路径

- 指定范围为空、非法 PMID、未选择治疗关联时不提交。
- 预估为 0 仍允许创建但给出说明；Preview 过期后禁用确认并要求重新预览。
- Preview 或创建失败保留表单；运行控制失败保留当前状态并给出恢复操作。
- 退回修改必须至少选择一个需修改字段；拒绝必须填写原因；草稿版本冲突提示刷新后比较。
- 已完成审核禁用继续编辑和决定，结果通过状态区域向辅助技术播报。

## 受影响旧行为

- 发现策略页保留查看、暂停和恢复，不再提供旧的“立即运行”。
- 保留现有公开 Knowledge、Ask、Landing 与结构化 Evidence 行为。
- 不改变接口、鉴权、环境变量或数据库结构；所有业务文案使用中文，文献原文保持原语言。
