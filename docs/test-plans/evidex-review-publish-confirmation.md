# 审核发布确认验收记录

日期：2026-09-17

## 验收范围

- 输入：一条可审核、无阻断问题的待审任务，包含发布预览、当前草稿、文献来源与预期发布版本。
- 正常路径：选择“审核并发布”后，先核对拟新增/已发布修改数、证据等级与分级依据、文献标识与来源范围、当前/发布后版本，以及每条证据结论的核心字段；填写批准说明后发布。
- 可观察输出：发布成功提示必须使用决定接口实际返回的 `releaseVersion`，随后重新读取任务并将已发布任务切为只读。
- 边界条件：首次发布没有当前版本或服务端暂未返回发布预览时，界面使用明确的缺省说明，不推断正式知识的等级差异。
- 失败路径：空批准说明不能提交；阻断性质量问题仍不能发布；409 草稿版本冲突继续保留重新读取入口；未保存离开提醒不变。
- 受影响的旧行为：退回修改、拒绝候选、草稿保存、字段来源定位与终态状态展示。
