# Evidex 治疗证据页测试记录

## 目标与范围

- 用户可在 `/zh/evidence` 选择癌种和变异，查看治疗证据综述、临床研究、监管信息与原始来源。
- 页面继承 Landing Page 的浅蓝、品牌蓝与半透明层级，并面向 1024px 以上桌面浏览器。
- 对外界面不展示开发阶段、版本号、接口路径、内部证据编号或服务实现流程。
- 页面保留现有同源请求、2 个癌种、5 个规范变异和 6 个直接证据组合，数据行为不变。

## 验收场景

| 场景       | 输入 / 前置条件                | 可观察结果                                                       |
| ---------- | ------------------------------ | ---------------------------------------------------------------- |
| 默认查询   | `NSCLC + EGFR p.L858R`         | 提交原有结构化请求，展示综述、治疗、证据、来源更新时间和免责声明 |
| 新组合选择 | 选择 `CRC + KRAS p.G12D`       | 基因自动切换为 KRAS，并提交规范的 SNV 请求体                     |
| 公开页面   | 初始态与结果态                 | 不出现体验版、版本号、后端、接口、知识版本或内部证据编号         |
| 选项目录   | 页面或调用方读取目录           | 可见 2 个癌种、5 个变异和 6 个直接证据组合                       |
| 综述失败   | 返回 `SUMMARY_UNAVAILABLE`     | 用面向用户的提示说明综述暂时无法呈现，结构化证据仍完整可见       |
| 越界输入   | 返回 `OUT_OF_SCOPE`            | 显示当前收录范围提示，不伪造医学结果                             |
| 依赖失败   | 请求返回 HTTP 错误             | 显示可重试提示；请求期间禁止重复提交                             |
| 回归       | 首页、定价页、鉴权页与匿名 API | 原有 E2E 行为保持通过                                            |

## 完整验收

- `pnpm verify`：通过；24 个测试文件、172 个测试全部通过。
- 覆盖率：整体语句 97.56%、分支 91.13%、函数 99.41%、行 97.81%；证据页组件语句 96.74%、分支 84.55%、函数 100%、行 98.30%。
- `pnpm verify:full`：在不包含开发密钥的隔离工作区中验证生产构建；浏览器 E2E 覆盖对外证据查询页、中英文首页、动效降级、桌面导航和鉴权回归。
- 浏览器手动回归以 1024px 至 1920px 桌面视口为当前范围；真实查询结果为 4 个治疗方案、6 条临床证据与 5 条监管记录。

## 展示边界

- 论文题名、短原文摘录、基因、HGVS、PMID、研究名称和监管申请号保留原值；其他界面文案为中文。
- 新增记录未配置专用中文结构化释义时使用中文缺省提示，不能把未翻译英文当作中文结论。
- 页面内部仍按关联与证据标识进行可靠回连，但不向用户展示这些内部编号。
