# Evidex V0.2 前端体验页测试记录

## 目标与范围

- 用户可在 `/zh/evidence` 选择癌种和变异，体验规范化、已发布知识检索、受约束综述与来源追溯。
- 页面从固定 `NSCLC + EGFR p.L858R` 升级为 2 个癌种、5 个规范变异、6 个直接证据组合。
- 浏览器只调用同源 `/api/v1/evidence-answer`；选择目录由 `/api/v1/evidence-options` 和共享 catalog 提供。
- 页面不读取 Neon 或 Evolink 密钥，首次未缓存查询可能触发一次服务端 Evolink 调用。

## 验收场景

| 场景       | 输入 / 前置条件                | 可观察结果                                                         |
| ---------- | ------------------------------ | ------------------------------------------------------------------ |
| 默认查询   | `NSCLC + EGFR p.L858R`         | 提交原有结构化请求，展示综述、治疗、证据、FDA 来源、版本和免责声明 |
| 新组合选择 | 选择 `CRC + KRAS p.G12D`       | 基因自动切换为 KRAS，并提交规范的 SNV 请求体                       |
| 选项目录   | 页面或调用方读取 catalog       | 可见 2 个癌种、5 个变异和 6 个直接证据组合                         |
| 模型失败   | API 返回 `SUMMARY_UNAVAILABLE` | 综述提示不可用，结构化证据仍完整可见                               |
| 越界输入   | API 返回 `OUT_OF_SCOPE`        | 显示 V0.2 范围提示，不伪造医学结果                                 |
| 依赖失败   | API 返回 HTTP 错误             | 显示可重试提示；请求期间禁止重复提交                               |
| 回归       | 首页、定价页、鉴权页与匿名 API | 原有 E2E 行为保持通过                                              |

## 展示边界

- 论文题名、短原文摘录、基因、HGVS、PMID、研究名称和接口路径保留原值；其他界面文案为中文。
- 新增记录未配置专用中文结构化释义时使用中文缺省提示，不能把未翻译英文当作中文结论。
- 页面展示的模型回答必须用 `associationId`、claim ID 和 FDA approval ID 回连结构化证据，不按数组下标或药名猜测。
